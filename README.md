# Cinema Dream 🎬

Веб-приложение «онлайн-кинотеатр» — расчётная работа по дисциплине «Интернет-программирование».  

---

## О проекте

**Cinema Dream** — видеосервис для просмотра фильмов, сериалов и аниме. Пользователи могут искать и фильтровать контент, смотреть через встроенный HTML5-плеер и оставлять отзывы с оценкой.

---

## Стек технологий

| Слой | Технология |
|------|-----------|
| Сервер | Node.js, Express 5 |
| Шаблонизатор | express-handlebars (.hbs) |
| База данных | Microsoft SQL Server 19 (пакет `mssql`) |
| Стили | SCSS → CSS |
| Аутентификация | Сессии в памяти, HMAC-SHA256 с солью |
| Конфигурация | dotenv |

---

## Быстрый старт

```bash
# Установить зависимости
npm install

# Скомпилировать SCSS
npm run build:sass

# Создать .env файл (пример ниже)
# Запустить сервер
node app.js
```

**.env:**
```env
DB_SERVER=localhost
DB_PORT=1433
DB_USER=your_user
DB_PASSWORD=your_password
DB_NAME=cinema_dream
DB_CONNECT_TIMEOUT=30000
```

## Маршруты

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/` | Главная — случайные фильмы, сериалы, аниме |
| GET | `/content?category=movies\|serials\|anime` | Каталог с фильтрацией |
| GET | `/player/:type/:id` | Страница плеера |
| GET | `/api/search?query=` | Поиск по названию (JSON) |
| GET | `/api/filter?year=&rating=&genres[]=&sort=` | Фильтрация контента (JSON) |
| GET | `/api/genres?category=` | Список жанров (JSON) |
| GET/POST | `/api/comments` | Чтение и добавление комментариев |
| POST | `/api/register`, `/api/login`, `/api/logout` | Аутентификация |
| GET | `/api/me` | Текущий пользователь |

## База данных

БД `cinema_dream` в MS SQL Server, 7 таблиц:

- **Genres** — справочник жанров
- **Movies** — фильмы (метаданные + путь к файлу)
- **MovieGenres** — связь «многие ко многим» фильмы ↔ жанры
- **Series** — сериалы и аниме (различаются по полю `type`)
- **SeriesGenres** — связь «многие ко многим» сериалы ↔ жанры
- **Seasons** — сезоны сериала
- **Episodes** — эпизоды сезона

Все связи через `FOREIGN KEY` с `ON DELETE CASCADE`.

## Функциональность

- **Поиск** — живой поиск с debounce по всем типам контента
- **Фильтрация** — по году, рейтингу, жанрам; сортировка по названию/рейтингу/году
- **Плеер** — HTML5 `<video>` с метаданными, описанием и отзывами
- **Авторизация** — регистрация/вход, токен сессии в `localStorage`, HMAC-SHA256 пароли
- **Комментарии** — оценка 1–10, текст до 100 слов, один отзыв на пользователя на контент
- **Адаптивность** — количество карточек подстраивается под размер экрана (4–8 в зависимости от breakpoint)
